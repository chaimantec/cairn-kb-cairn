# Glossary

**BYOK** — "bring your own key". Cairn's model for the AI chat: you supply an
API key from DeepSeek or OpenRouter and pay them directly, rather than paying
Cairn for a bundled allowance. See [bring your own key](bring-your-own-key.md).

**Cairn** — both the extension, and the thing it is named after: a stack of
stones left on a trail by earlier walkers to mark the way.

**Catalog** — the shared, community-built list of courses. Anyone signed in can
add to it; enrolling from it needs no account. See [the catalog](catalog.md).

**Course** — a YouTube playlist plus metadata: code, title, instructor, an
ordered lecture list, and optionally a course website and a knowledge base.

**Difficulty** — one of the two rating axes, 1–5. See [ratings](ratings.md).

**Enrolment** — your personal link to a catalog course. Yours alone; it never
appears in the shared entry.

**Guest mode** — using Cairn without signing in. Everything personal works and
stays in your browser.

**`kb_read` / `kb_list`** — the tools the study chat uses to read a course's
knowledge base. They appear as chips in the transcript when they run. See
[what the chat can look up](chat-tools.md).

**Knowledge base (KB)** — a public GitHub repository compiled from a course's
own materials, which the chat reads before answering and cites. See
[knowledge bases](knowledge-bases.md).

**`kbUrl`** — the field on a catalog entry holding a course's knowledge base
repository URL. Set by the entry's creator. See
[attaching a knowledge base](attach-a-knowledge-base.md).

**Lecture** — one video in a course, with a position, a duration, and your
progress against it.

**Live tab** — the sidebar tab tied to whatever is playing right now, holding
Notes and Chat. See [the Live tab](live-tab.md).

**Memory** — standing instructions the assistant keeps about how you like to be
answered. Stored in your browser, capped at 50. See [chat memory](chat-memory.md).

**Nearby window** — the span in which a note surfaces as the lecture plays: from
10 seconds before its timestamp to 80 seconds after.

**Nickname** — your public identity, auto-generated from an adjective and a
noun, changeable in Settings. There are no real names or avatars in Cairn.

**Note** — a piece of text attached to a lecture, usually pinned to a timestamp.
Private by default; published, it becomes a trace.

**Personal / Public** — a note's visibility. Personal is yours alone; Public is
visible to everyone watching that lecture, under your nickname.

**Side panel** — Chrome's built-in panel beside the page, where the Cairn
sidebar lives.

**Study chat** — the optional AI assistant in the Live tab, scoped to the
lecture playing. See [the study chat](study-chat.md).

**Thinking level** — how much reasoning a supporting model does before
answering, from `off` to `max`. See [models and thinking levels](models-and-thinking.md).

**Timeline bar** — the strip above the note list showing where in a lecture
notes cluster. Click it to seek.

**Trace** — a public, timestamped note left for other learners. Cairn's central
idea. See [traces and notes](traces-and-notes.md).

**Usefulness** — the other rating axis, 1–5: how essential a lecture is.

**`SEE_ALSO.md`** — the file in a knowledge base listing related courses' knowledge
bases, and the only way the chat learns a sibling repository exists.
